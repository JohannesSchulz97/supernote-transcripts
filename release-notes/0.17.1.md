# Supernote Transcripts 0.17.1

This prerelease makes plugin Settings and Source settings easier to scan and use.

- Connection groups provider setup, the default transcript folder, and usage and costs. Recognition gives direct access to the prompt library. Advanced updates contains concurrency and retries.
- Recognition quality and automatic check depth use labeled, keyboard-accessible choices. Save remains visible while scrolling.
- Source settings puts the source name, notebook scope, and transcript folder first. Exclusions, sync, and advanced recognition have their own sections.
- Editing preserves focus when background updates arrive in API-mode Settings. Opening conditional source options keeps the active section open.

## Upgrade

Download the manual-install ZIP and replace `main.js`, `manifest.json`, and `styles.css` in your existing plugin folder. Keep your saved settings and state files. See the [installation guide](../docs/installation.md).
